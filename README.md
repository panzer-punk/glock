# Glock

[English](README.en.md)

POC сервиса распределённых блокировок, ориентированного в первую очередь на PHP. Предоставляет механизм для создания mutex в PHP-приложениях через Unix-сокет.

## Возможности

- **Автоматическое освобождение блокировок** — при разрыве соединения клиента все удерживаемые им блокировки снимаются.
- **Блокирующие и неблокирующие блокировки** — `lock()` ждёт освобождения, `tryLock()` возвращает результат немедленно.
- **Разделение по namespace** — блокировки изолированы внутри namespace; один и тот же ключ в разных namespace не конфликтует.

## Ограничения POC

Это **не финальная версия** POC. Следующее сознательно не входит в текущую реализацию или ещё в процессе:

- **Распределённость** — сервис работает как один процесс; координация между несколькими инстансами не реализована.
- **Сессии и отказоустойчивость** — механизм сессий и поведение при сбоях ещё в разработке.
- **PHP-клиент** — `GlockClient.php` находится в разработке и не является финальной версией.
- **Структура проекта** — расположение пакетов и файлов может измениться.

## Структура

```
cmd/glock/          — сервер (Go)
internal/           — логика блокировок, namespace, протокол
php/GlockClient.php — PHP-клиент
php/load_test*.php  — нагрузочные скрипты
```

## Быстрый старт

Запуск сервера:

```bash
go run ./cmd/glock
```

Пример использования из PHP:

```php
require 'php/GlockClient.php';

$client = new GlockClient('/tmp/glock_test.sock');
$client->connect();

$secret = $client->lock('default', 'my-resource');
try {
    // критическая секция
} finally {
    $client->unlock('default', 'my-resource', $secret);
    $client->close();
}
```

Неблокирующая попытка:

```php
if ($client->tryLock('default', 'my-resource')) {
    // блокировка получена
}
```
